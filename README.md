# Movie Recommendation System

## Project Description
This is a Python + SQLite based terminal application.

Users can:
- Add users
- Add genres
- Add movies
- Rate movies
- View top rated movies
- Get movie recommendations

## Technologies Used
- Python
- SQLite

## Features
- Email validation
- Movie rating system
- Genre management
- Recommendation system
- Top rated movies

## Database Tables
- users
- genres
- movies
- ratings

## How to Run

```bash
python main.py
```
